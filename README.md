# ⏰ Digital Clock

A simple digital clock built with Python and Tkinter that displays the current time in real time.

## ✨ Features

- ⏰ Displays the current time
- 🔄 Updates automatically every second
- 🖥️ Simple graphical interface
- 🐍 Built using Python and Tkinter

## 🛠️ Technologies Used

- Python
- Tkinter

## 🚀 How to Run

```bash
python digital_clock.py
```

## 📚 What I Learned

- Working with Tkinter widgets
- - Using the `after()` method for live updates
- Formatting date and time
- Building a real-time GUI application
